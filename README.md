# 🎮 Learning XP System

To make the learning journey more interesting, major progress can be treated like a game.

| Activity | XP |
|:---|---:|
| 📖 Learn a concept | +10 XP |
| 🧠 Understand it | +15 XP |
| ⌨️ Write it yourself | +20 XP |
| 🧪 Experiment | +25 XP |
| 🐛 Find & fix a bug | +30 XP |
| 🧩 Solve a problem | +40 XP |
| 🏗️ Build a mini-project | +100 XP |
| 🚀 Build a major project | +250 XP |

> XP is only a motivation system. It does not represent real skill mathematically.

# 📚 Recommended Learning Approach

For every major topic:

### 1️⃣ Learn

Understand the concept.

### 2️⃣ Write

Type the code yourself.

### 3️⃣ Experiment

Change the code and observe what happens.

### 4️⃣ Break

Try to make it fail.

### 5️⃣ Debug

Find out why it failed.

### 6️⃣ Practice

Solve problems without following an example.

### 7️⃣ Build

Use the concept in a project.

### 8️⃣ Document

Explain what was learned in your own words.
